# Tegami

A notification card for Ryoku shaped like a small letter on the desktop. The sender and time sit above an editorial headline, while the app seal, message and quiet action row keep each notice easy to scan; urgent letters gain a vermilion edge and timed ones drain along the foot.

Tegami follows your colour scheme, type and reduced-motion setting, and can show the sender's artwork when notification images are enabled. Install it from RyoStore -> Notifications, then pick it in Settings -> Overlays.
