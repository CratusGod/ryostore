Soft Column is the "aayushchalise" entry (configs/aayushchalise/config.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by aayushchalise. Ported for Ryoku: Logo changed from kitty PNG (~/.config/fastfetch/images/arch.png) to builtin Arch logo; added padding.right 2. Removed the OS-age `command` module (ran `stat -c %W /`); no shell-out allowed. packages format {} resolved to the empty am-system field (0 on Arch); changed to {pacman}. Upstream memory key icon U+FB19 is a Hebrew presentation form, not a memory glyph; replaced with U+F035B (nf-md-memory). Removed per-module keyColor 34; accent now flows through display.color.keys #c6a0f6. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: it draws the running distribution's small built-in logo rather than the Arch mark upstream shipped, the OS key shows Tux instead of the Arch glyph, and its package count uses Fastfetch's default format, which names whichever package manager the system uses (pacman, rpm or xbps). The display key's U+F878 is a Nerd Fonts 2 code point that no font Ryoku ships still contains, so it drew an empty box; it is now the Nerd Fonts 3 monitor glyph (U+F0379). Pick an emblem in Settings -> Fastfetch to show art instead of the logo.
