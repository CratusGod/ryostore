Wide Card is the "kuruma-config" entry (configs/kuruma-config/config.jsone) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by kuruma-config. Ported for Ryoku: Logo image shuf substitution replaced with the built-in Arch logo. Fixed upstream JSON bug: the .jsone file had a trailing comma after the final custom key; also the .jsone extension (content is JSONC). Per-module keyColor blue removed (the hardware box had none); blue {#34} mapped to the {#keys} slot (display.color.keys=#61afef). Malformed bare {#38} value color and trailing {#keys}/{#34} cruft removed from formats; values now follow display.color.output=#c5c9c5. GPU format {vendor} {name} ({type}) changed to {name} ({type}) to drop the doubled vendor. Removed the commented-out colors module block. Kept the two stacked rounded boxes; normalized the label field so the right borders align on every row; added $schema and the ryoku header comment. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the built-in logo now follows the running distribution instead of always drawing Arch's, and the WM key shows a window glyph instead of the Windows logo.
