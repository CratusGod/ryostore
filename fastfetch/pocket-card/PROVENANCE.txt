Pocket Card is the "kuruma-config" entry (configs/kuruma-config/mini.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by kuruma-config. Ported for Ryoku: Logo image shuf substitution replaced with the built-in small Arch logo. Per-module keyColor blue removed; blue {#34} mapped to the {#keys} slot (display.color.keys=#61afef). Malformed bare {#38} value color and trailing padding/{#34}/{#keys} cruft removed from formats; values now follow display.color.output=#c5c9c5. Header changed from a whitespace-only key to a keyless title module carrying the hostname bar; dropped the ellipsis flourish. Added an aligned inner divider so each row is box glyph + icon + label + divider + value. Added $schema and the ryoku header comment. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the small built-in logo now follows the running distribution instead of always drawing Arch's, and the package count is back on Fastfetch's default format, which names whichever package manager the system uses (pacman, rpm or xbps).
