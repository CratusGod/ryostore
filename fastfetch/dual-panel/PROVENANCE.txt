Dual Panel is the "kuruma-config" entry (configs/kuruma-config/config2.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by kuruma-config. Ported for Ryoku: Logo image shuf substitution replaced with the built-in small Arch logo (small chosen to keep width under 100 columns). Per-module keyColor magenta/cyan removed; dominant magenta {#35} mapped to the {#keys} slot (display.color.keys=#c678dd); cyan {#36} kept as a palette reference for the Hardware panel. Malformed bare {#38} value color and trailing {#keys} cruft removed from formats; values now follow display.color.output=#c5c9c5. GPU format {vendor} {name} ({type}) changed to {name} ({type}) to drop the doubled vendor (AMD AMD) and narrow the line. Content rows normalized to a fixed label field so the inner divider column aligns; kept the open System/Hardware panel headers. Added $schema and the ryoku header comment. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the small built-in logo now follows the running distribution instead of always drawing Arch's.
