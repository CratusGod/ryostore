Ported for Ryoku: Replaced the TF2 soldier ASCII art (file: %USERPROFILE%\\...\\Icon_soldier.txt) with the built-in small Arch logo. Removed the four leading breaks that centred content beside the tall soldier art. Routed the dominant yellow through display.color.keys ({#keys}): key labels, the title host, the OS variant and the underlined media title; kept {#blue} and the red percent gauges as terminal-following refs. Fixed the title host colour: upstream's {8} (pre-coloured host) overrode the intended yellow, so it now uses {host-name} to apply the accent. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the small built-in logo now follows the running distribution instead of always drawing Arch's, and the OS key shows Tux instead of upstream's Windows logo.
