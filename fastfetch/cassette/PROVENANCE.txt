Cassette is the "config 9" entry (configs/9.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by esplatanukis2-wq. Ported for Ryoku: Fixed the upstream parse failure: inline // comments embedding double-quotes and apostrophes (notably the one right after 'modules: [' and the display.color comments) crash strict/regex JSONC loaders though fastfetch tolerates them; removed all inline comments. Removed the iterm PNG logo (a personal image path) and set logo to none; the design is a self-framed boxed readout. Replaced the 'command' echo song ('Akina Nakamori - ...', a real artist) with a neutral static cassette line. Dropped the right-hand box border on content rows: upstream positioned it with fixed trailing spaces tuned to the author's values and it cannot align across variable output; kept every box's top/bottom rules and left border at equal width (62). Fixed formats: font {font2}->{font1} (was empty), monitor to '{width}x{height} @ {refresh-rate} Hz', memory to numbered {1}/{2}({3}). Routed the green key accent through {#keys} and the magenta title through {#title}; other mini-box colours stay ANSI names that follow the terminal theme. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the OS key shows a Linux penguin instead of upstream's Linux Mint mark.
