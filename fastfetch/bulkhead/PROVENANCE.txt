Bulkhead is the "Cmdr_Scotty" entry (configs/Cmdr_Scotty/config.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by Cmdr_Scotty. Ported for Ryoku: Replaced the image logo (auto PNG, width 64) with the built-in Arch logo. Narrowed all four box-frame rules to an equal 54-column width so they align beside the logo. Restored the Miscellaneous section icons (clock, globe, music note, calendar) that upstream had lost to blank spaces. Routed the dominant red accent through display.color.keys and removed the per-module red keyColor on the Hardware section and title. Kept the green/blue/magenta section keys and the yellow frame ({#33}, matching upstream's \u001b[33m) as terminal-palette references. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets. The preset now ships that design's own emblem (tsukikko.png): Tsukikko, the emblem the upstream config shipped in its images folder. It installs beside the config and is referenced from it; the artwork is redistributed as it appears in the upstream MIT-licensed collection and remains the property of its creators. Swap it in Settings -> Fastfetch, or delete the file to fall back to the running distribution's built-in logo.
