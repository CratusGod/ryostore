Install Log is the "config 2" entry (configs/2.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by harilvfs. Ported for Ryoku: Logo changed from kitty-direct PNG glob to builtin Arch logo; added padding.right 2. Removed the OS-age `command` module (ran `stat -c %W /`); no shell-out allowed. Dropped the second gpu module (format {3}=driver); the single gpu module already lists both GPUs. packages format {} resolved to the empty am-system field (0 on Arch); changed to {pacman}. Removed per-module keyColor 34; accent now flows through display.color.keys #56b6c2 so the theme can recolour it. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the built-in logo now follows the running distribution instead of always drawing Arch's, the OS key shows Tux instead of the Arch glyph, and the package count is back on Fastfetch's default format, which names whichever package manager the system uses (pacman, rpm or xbps).
