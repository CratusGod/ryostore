Grimoire is the "configs/friefetch" entry (configs/friefetch) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed. Ported for Ryoku: Replaced the Frieren ASCII art (file: ~/.config/fastfetch/logo/frieren.txt) with the built-in Arch logo. Deleted every command module and replaced them with built-ins: kernel (uname), uptime, wm ($XDG_CURRENT_DESKTOP), memory (free), cpu (lscpu), disk (df); Owner now uses title/{user-name} (was echo $USER, so lower-case not upper-case). Dropped the OS-age row (disk {days}) per port scope. Kernel shows the full {release}, uptime shows fastfetch's {formatted}, and CPU shows the full {name} instead of the sed-trimmed upstream values. Disk uses a compact used/total (no filesystem) to fit the 22-column value field. Rebuilt the footer as a static custom line 'WE ARE LIBRE !' (was an echo command; dropped the CJK phrase). Moved the monochrome white into display.color.keys so the card recolours. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the built-in logo now follows the running distribution instead of always drawing Arch's.
