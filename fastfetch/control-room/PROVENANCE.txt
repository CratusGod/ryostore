Control Room is the "configs/rorfetch" entry (configs/rorfetch) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by rorfetch. Ported for Ryoku: Logo: dropped the kitty image ($HOME/Pictures/fastfetch_imgs/*.png); set logo to none so the four panels render full-width. Removed all 18 command modules. Host: hostnamectl --static command -> builtin host module ({name}). Uptime: /proc/uptime awk command -> builtin uptime module ({formatted}). CPU Usage: /proc/stat awk bar command -> builtin cpuusage module ({avg-bar}). RAM: /proc/meminfo awk command -> builtin memory module ({used} / {total}). RAM Usage: awk bar command -> second memory module ({percentage-bar}). Main disk: df command -> builtin disk module for /; its Usage -> second disk module ({size-percentage-bar}). Display: niri command -> builtin display module ({width}x{height} @ {refresh-rate}Hz); the Display Settings sub-row folded into it and removed. Packages: kept the Packages parent label; Pacman/Flatpak/Total rows -> builtin packages module ({pacman}/{flatpak-all}/{all}). Network: ip command -> builtin localip module ({ipv4}). Skull footer: printf command -> inline custom module carrying the same 256-colour skull gradient. Deleted rows fastfetch cannot produce without shelling out: GPU Usage, the author-specific /mnt/data (Data) disk and its Usage, and the separate AUR count (no builtin AUR placeholder). Usage bars show the bar only (fixed 16 wide); upstream centred a zero-padded percentage inside the bar via awk, which builtins cannot reproduce, so the numeric label was dropped for stable width. GPU: dropped the [{type}] suffix (only the discrete GPU is shown) to save width. Colours routed through slots: border 88 -> {#keys}, dotted rail 59 -> {#separator}, body text 252 -> {#output}, green 118 -> {#title}, all defined as hex in display.color; per-section 256-palette accents (81/178/141/208/69/193/226/111/33/196) kept as-is. Narrowed every panel from ~70 to 54 visible columns; recomputed all border dash runs and dotted-rail lengths to one shared width. display: dropped showErrors (it only hid command failures); added disableLinewrap true to protect the box; kept brightColor and separator; percent type set to bar. Terminal/Shell/Font/Cursor are runtime-variable rows: rails are tuned to the measured value width, so terminals/shells whose reported name differs in length from the reference land a couple of columns short or long (inherent to fastfetch boxes). terminalfont (Font) row is kept for identity but does not resolve under the sandbox terminal (fastfetch reports 'omp'), so it is absent from the measured dump; it renders normally on kitty. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the SYSTEM heading and the OS key show a Linux penguin instead of the Arch mark, and the Pacman row is now System, counting whichever package manager the system uses (pacman, rpm or xbps).
