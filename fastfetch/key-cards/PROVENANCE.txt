Key Cards is the "config 7" entry (configs/7.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by Beastboy999cr. Ported for Ryoku: Replaced the image logo (auto PNG path) with the built-in Arch logo. Replaced the OS key placeholder {icon} with a static Arch glyph. Dropped the broken {#38} value color codes; values now use the terminal foreground. Routed the red key/border accent through display.color.keys and the two green rows (Display, Uptime) through display.color.title; removed per-module keyColor. Unified the second card's borders to the red accent (upstream left them uncolored). Shortened the GPU format to {name} (dropped vendor/type) to keep width under 100 columns. Recomputed every box row to an equal 14-column width so the borders line up. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the built-in logo now follows the running distribution instead of always drawing Arch's, the OS key shows Tux instead of the Arch glyph, and the WM key shows a window glyph instead of the Windows logo.
