Arc Reactor is the "config 5" entry (configs/5.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed. Ported for Ryoku: Replaced the kitty-direct PNG logo (Iron Man art, trademark) with the built-in Arch logo. Renamed the fictional label STARK_SH to SHELL, keeping the same 9-char field so columns stay aligned. Replaced the upower 'command' battery module (format 'ARC REACTOR AT {}') with the builtin battery module ('{capacity} [{status}]'). Moved the design palette into display.color and routed the red title + divider rules through the {#title} slot; kept keys=magenta as the accent. Kept REACTOR/H.U.D/POWER (generic industrial terms); on dual-GPU machines two VISUALS lines appear (upstream {2}, unchanged). It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets.

Ported for every Ryoku edition: the built-in logo now follows the running distribution instead of always drawing Arch's.
