Deep Specs is the "ghosttree" entry (configs/ghosttree/config.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by ghosttree. Ported for Ryoku: Logo changed from auto PNG (~/.config/fastfetch/images/cat.png) to builtin Arch logo; added padding.right 2. Removed the OS-age `command` module (ran `stat -c %W /` with a mtime fallback); no shell-out allowed. packages format {} resolved to the empty am-system field (0 on Arch); changed to {pacman}. host format '{5} {1} Type {2}' was ~77 cols (vendor+family+product, redundant and wrapping); narrowed to {1} (model family). cpu format '{1} ({3}) @ {7} GHz' printed '@ 5.26 GHz GHz' because {7} already carries the unit; changed to '{1} ({3}) @ {7}'. gpu format '{1} {2} @ {12} GHz' printed 'AMD AMD ...' ({1} vendor duplicates {2}) and an empty {12} frequency; changed to '{2}' (name only). monitor default line was 113 cols (added physical mm/ppi); narrowed to '{width}x{height} @ {refresh-rate} Hz'. Per-module keyColor 31/32/33 replaced by display.color slots: keys #e06c75 (system), title #98c379 via keyColor (desktop), separator #e5c07b via keyColor (hardware); the ' -> ' separator now renders yellow (was default foreground). It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets. The preset now ships that design's own emblem (cat.png): The cat photograph the upstream config shipped in its images folder. It installs beside the config and is referenced from it; the artwork is redistributed as it appears in the upstream MIT-licensed collection and remains the property of its creators. Swap it in Settings -> Fastfetch, or delete the file to fall back to the running distribution's built-in logo. The package count now counts whichever native package manager the edition uses (pacman, rpm or xbps), so the preset fits every Ryoku edition.
