Terminal Online is the "kitty-cachyos" entry (configs/kitty-cachyos/config.jsonc) from the community awesome-fastfetch-collection (https://github.com/Chintanpatel24/awesome-fastfetch-collection), MIT licensed, originally by kitty-cachyos. Ported for Ryoku: Replaced the image logo (/home/mike PNG path) with the built-in Arch logo. Dropped both command modules: replaced the Shell command with the built-in shell module and removed the OS Age command (days-since-install has no built-in equivalent). Kept the signature TERMINAL ONLINE header line verbatim (ANSI palette colors plus a one-off 256-color orange). Replaced the packages format, which returned 0 on fastfetch 2.66, with the default packages format that correctly reports pacman and flatpak. Routed the dominant red accent through display.color.keys and removed the per-module red keyColor on the OS/kernel/packages rows; kept the green/yellow/blue/magenta sections as terminal-palette references. It ships as a single config file using only built-in Fastfetch modules, with no external runtime assets. The preset now ships that design's own emblem (girl.png): The portrait the upstream config shipped in its logo folder. It installs beside the config and is referenced from it; the artwork is redistributed as it appears in the upstream MIT-licensed collection and remains the property of its creators. Swap it in Settings -> Fastfetch, or delete the file to fall back to the running distribution's built-in logo.

Ported for every Ryoku edition: the OS key shows Tux instead of the Arch mark.
