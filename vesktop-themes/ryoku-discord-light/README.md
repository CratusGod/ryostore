# Ryoku Discord Light

The light version of the Ryoku Discord theme: same layout, art and animations as the main theme.

made by Ron. source, issues and the other versions: [https://github.com/niqqudim/ryoku-discord](https://github.com/niqqudim/ryoku-discord) (this is [`theme/templates/ryoku-light.theme.css`](https://github.com/niqqudim/ryoku-discord/blob/main/theme/templates/ryoku-light.theme.css)).

## Enable the theme

install through ryostore, then open **Vesktop → Settings → Themes** and enable **Ryoku Light**. enable one Ryoku theme at a time. installing does not enable a theme or change quickCSS.

The file is a settings file: every option is a CSS variable at the top, so you can open it and change colours, fonts, animations and art.

## Network resources

The installed file holds only the settings. when the theme is enabled, Vesktop gets the theme itself from a github pages site:

- `https://niqqudim.github.io/ryoku-discord/build/ryoku.css`

the code also imports some google fonts from: fonts.googleapis.com, fonts.gstatic.com
it also imports some icons from davart154.github.io
